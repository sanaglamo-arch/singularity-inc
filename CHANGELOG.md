## 2026-06-20

### Рынок: мульти-факторная доля + победа «Монополия» · `af83da0` (game v90, ui v88, i18n v89, config v78)
- **Что:** доля рынка теперь зависит не только от юзеров — в конкурентную ценность модели добавлены БЕЗОПАСНОСТЬ и ЛЕГАЛЬНОСТЬ (множитель доверия), сверх одобрения. Добавлена ВТОРАЯ победа — «Монополия»: удержать долю ≥98% в течение 14 игровых дней на версии ≥6 → захват рынка (отдельная золотая концовка, наравне с Сингулярностью). В World-табе — живой прогресс захвата.
- **Зачем:** владелец — захват рынка слабой моделью «на рекламе» не должен быть захватом; доля должна зависеть от мощности+юзеров+безопасности+легальности; захват рынка — сложная отдельная цель/концовка.
- **Проверено:** множители центрированы на старте (75) → на baseline экономика не меняется; сим — обычная игра доходит до Сингулярности (agi@день124, доля median 0.86/max 0.97), намеренное доминирование выигрывает монополией платёжеспособно (золотой экран). node --check, RU+EN паритет, 0 ошибок, 390+1280 без оверфлоу.

### Цена: окно бесплатной правки + формулировка счёта · `9398fd2` (game v89, ui v87, i18n v88, config v77)
- **Что:** после смены цены 10с можно свободно корректировать (откатить ошибку) до включения минутного кулдауна. Убрано слово «покрываешь» (bill_covered → «хватает ✓»).
- **Зачем:** слепой перетест назвал 60с-кулдаун главной фрустрацией (мешал учиться ценообразованию); решение владельца — окно правки.
- **Проверено:** правки в пределах 10с применяются, далее блок до 60с, новое окно после; node --check, RU+EN паритет.

### Сейв: не стирать прогресс при ошибке init + онбординг переживает потерю сейва · `269591a` (game v88, main v61)
- **Что:** main.js больше не вызывает reset() (стиравший сейв) при ошибке инициализации; имя компании и флаги онбординга вынесены в переживающие-reset ключи.
- **Зачем:** баг «при обновлении страницы заново все обучающие катсцены + запрос имени» И «баланс иногда исчезает» — одна первопричина (reset стирал хороший сейв).
- **Проверено:** новый игрок видит онбординг; опытный со стёртым сейвом — нет; обычный reload без изменений.
