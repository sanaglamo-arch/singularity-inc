## 1. Видение и столпы
Ты основатель ИИ-компании: из гаража к AGI. Покупаешь железо и помещения, выпускаешь всё более мощные модели, **назначаешь цену на токены** и борешься за долю рынка с ривалами — пока кто-то не достигнет AGI.

**Столпы:**
1. **Строить выгодно** — каждое вложение ощутимо окупается (зашито в структуру, не подкручено).
2. **Честные деньги** — доход никогда не рисуется отрицательным; расходы идут счетами с дедлайном.
3. **Беды — следствие выбора, не рандом** — пожар/иск телеграфируются твоей же экономией на безопасности/законности.
4. **Скилл — ценообразование** — мощность÷цена даёт долю; сладкая точка дрейфует.
5. **Сложно, но проходимо** — 4 сложности, каждая выигрывается (доказано пруф-симом).

## 2. Кор-петля
```
клик (бутстрап) → деньги → железо (аренда=пасс.доход) + помещения (м²=место)
   → копишь Мощность → ВЫПУСК МОДЕЛИ → железо переходит из аренды в продакшен
   → ставишь ЦЕНУ ТОКЕНОВ → Мощность÷Цена = ДОЛЯ → доход = Цена×Доля×Спрос
   → строишь дальше (новое железо арендуется) → СЛЕД. ВЕРСИЯ (скачок мощности)
   → … → AGI = финальная версия = ПОБЕДА
```

## 3. Онбординг / первая сессия (прогрессивное раскрытие)
- Старт: баланс **$50**. Игра заставляет первое вложение — **старый ноут** (пасс. дохода нет, но открывает клик).
- 1 клик=$0.10 → 100 кликов=$10 → апгрейд клика за $10 (1 клик=$0.2) → 200 кликов=$40 → **мини-сервер $40** (пасс. доход $0.1/с) → копишь $50 → апгрейд клика до $1 → …
- **Teach-on-first:** первый сервер объясняет «сдаётся в аренду другим компаниям = твой пассив». Цена/доля открываются на ПЕРВОМ релизе модели. Метрики/помещения — когда перерастаешь комнату.
- Принцип: на старте видно мало (клик), системы вводятся по мере релевантности; ранние награды частые; наказания на онбординге минимум. Первый дофамин ≤90с (выпуск v1 = кат-сцена).

## 4. Экономика
### 4.1 Доход (цена токенов — сердце)
- Ценность **V = Мощность ÷ Цена**. **Доля рынка = V / (V + ΣV_ривалов).**
- **Доход = Цена × Доля × Спрос** (спрос растёт по эрам). Себестоимость = электричество за обслуженные токены.
- Три зоны (= сложности владельца): слишком дёшево → доля есть, но в минус; сладко → доля×маржа максимум; дорого → доля рушится + **общество злится** (гуджинг).
- **UI:** слайдер цены с живым превью («доля 23%, прибыль +$X/с, одобрение ↓»). Симуляция под капотом, поверхность читаема.
- **Ритм:** ставишь цену на релизе, перетюниваешь редко по подсказке («ривал обошёл — проверь цену»). Сладкая точка дрейфует с ростом мощности/спроса/ривалов.
- **До первой модели** дохода от токенов нет — пассив идёт от **аренды железа**.

### 4.2 Расходы (счета с дедлайном — доход не минусует)
- Все периодические траты копятся в счёт: **электричество** железа (кВт·ч) + **обслуживание помещений** ($/с) + **зарплаты** + **налог**.
- **Электро-счёт каждую игр.неделю**, плашка с дедлайном **1 игр.день**; просрочка → −30% выработки (пол, не 0). **Налог месячно.**
- **Бухгалтер** офлайн платит счета с комиссией (кусает рано, копейки поздно), отчёт «пока тебя не было».
- **Ликвидность** = покрываешь ли счета. Сигнал всегда виден («след. счёт через 3 дня ≈$188 · покрываешь ✓/⚠»).

## 5. Прогрессия: железо, помещения, поколения
### 5.1 Железо (тиры, аренда→продакшен)
- Покупаешь серверное оборудование. Параметры: **размер (м²)**, **аренда ($/с)**, **электро (кВт·ч)**, **цена**. (Полные тиры → `DESIGN-BALANCE-tiers.md`, ~9 ступеней из 25 реалистичных.)
- Железо **НЕ расходуется** — у него меняется роль: до релиза сдаётся в аренду (пассив), на релизе крутит твою модель (даёт Мощность).
- **Старые тиры устаревают** — лимит места + эффективность гонят вверх по лестнице.

### 5.2 Помещения (место + легитимность)
- Покупаешь помещения: **размер (м²)** (сколько железа влезет), **цена**, **обслуживание ($/с)**, **класс легитимности** (законность% / безопасность%).
- Подача: один выбор «насколько легитимно место» — «Подвал дёшево 60%/55%» ↔ «Бизнес-парк дорого 98%/95%» — с двумя прозрачными последствиями (законность→иски, безопасность→пожар).
- **м² помещений = естественный потолок** железа (не искусственные «1000 ноутов»).

### 5.3 Поколения (одна эволюционирующая флагман-модель)
- Всегда ОДНА текущая модель зарабатывает токенами.
- Развиваешь след. версию → строишь ещё железо; **новое железо в разработке арендуется** (бридж-доход), пока не выпустил.
- **Выпуск vN+1:** Мощность скачком, аренда нового железа прекращается, доля/доход пересчитываются, перетюнил цену. Строить выгодно дважды (аренда сейчас + крупнее модель потом).
- **AGI = финальная версия = победа.**

## 6. Параметры и метрики
**Эконом-показатели (что оптимизируешь, видны всегда):** Мощность · Деньги/Ликвидность · Доля рынка.
**3 метрики-риска (0-100), каждая = свой путь поражения:**
- **Безопасность** — риск/элайнмент → аварии + питает гнев государства + элайнмент-концовка.
- **Одобрение общества** → отмена.
- **Государство & закон** → запрет / иски / национализация.

## 7. События как СЛЕДСТВИЕ (не рандом) + флавор
- **Пожар** ← низкая физ-безопасность помещения → теряешь помещение+железо (откат, не смерть; восстанавливайся).
- **Иск государства** ← низкая законность помещения → штраф/давление.
- **Совет директоров** ← долгая низкая ликвидность → сначала предупреждение, потом форс-продажа (совет «появляется не сразу» = грейс).
- **Запрет** ← пол Безопасности/Государства.
- Поверх — лёгкий слой флавор-дилемм + **сатира-тикер** ривалов (идентичность). Старый движок 62 дилемм урезается: большинство «событий» теперь следствие %-ов.

## 8. Сотрудники (осязаемое управление метриками)
- **Юристы** → чуть ↓ недовольство государства. **Безопасники** → чуть ↓ риск опасности. **Маркетологи** → чуть ↑ одобрение. **Экономисты** → чуть ↓ налоги.
- Помогают и ощущаются, но не обнуляют (100 экономистов ≠ ноль налогов). Зарплаты идут в счёт.

## 9. Ривалы и гонка к AGI
- Ривалы выпускают свои модели, ставят свои цены, тянут долю. **Твоя доля относительна их V.**
- Рейтинг компаний по доле = и конкуренция, и **AGI-гонка** (кто первый выпустит финальную версию) в одной системе. HUD отрыва (зелёный/амбер/красный) телеграфирует, проигрываешь ли гонку.

## 10. Сложности (4)
Легко / Норма / Сложно / Невозможно различаются **давлением и темпом, не контентом:** агрессия/скорость ривалов, размер спроса, тяжесть событий при том же %, стартовая касса, налог, терпение совета, льгота на просрочку. Каждая проходима правильной игрой (пруф-сим). Чёрные лебеди — урезанный сабсет на Норме/Сложно (телеграф), полный на Невозможно.

## 11. Победа / поражение / концовки
- **Победа:** выпустил AGI-версию первым. Концовка по Безопасности/метрикам (aligned / misaligned / …) → **шеримая карточка** с панчлайном.
- **Поражения (телеграф до самого низа, рычаг всегда есть):** банкротство (ликвидность) · отмена (одобрение 0) · запрет (государство/безопасность 0) · иски→банкрот (закон 0).

## 12. Удержание / реиграбельность
- **Внутри забега:** офлайн-прогресс + срочность AGI-гонки + перетюн цены тянут назад.
- **Между забегами (заместитель престижа, без сбросов):** лестница сложностей · собрать все концовки (Зал славы) · альт-цели (без инцидентов / монополия по доле / спидран). Долгий хвост (D30) сознательно отдан будущему свободному режиму.

## 13. Модель времени
- **1 игр.день ≈ 60с.** Кампания ≈ 2.5-3 ч активной игры до AGI, растянуто на ~3-5 реальных дней офлайном. Календарь сверху: «14 марта, вечер» (дата+время суток, без минут).
- Офлайн-прогресс капнут на ~8-12 ч (welcome-back-нудж, не авто-проигрыш).

## 14. Вырезано / отложено
- **Свободный режим** (бесконечная гонка за капитализацией+состоянием) — будущее расширение, не сейчас.
- **Престиж-стек** (RP/артефакты/Cores/Legacy) — вырезан (когда-нибудь жил бы в свободном режиме).
- **Биржа/акции, прежняя двойная роль «компьюта», накопление-стока** — вырезаны.
