# v2 БАЗА — как играть (плейтест)

Открой :8080. По-русски по умолчанию.

## Петля
1. Жми КЛИК (сначала купи стартовый ноут — он включает клик).
2. Покупай железо (вкладка Железо). Простаивающее железо = доход с аренды.
3. Помещения (м²) = потолок железа. Дешёвые помещения = риск (пожар/иски).
4. Набери Мощность → выпусти модель (таймер обучения, клик ускоряет).
5. После релиза — поставь ЦЕНУ ТОКЕНОВ (слайдер, живое превью доля/юзеры/прибыль/одобрение). Дёшево = много юзеров, тонкая маржа; дорого = юзеры уходят + общество злится.
6. Плати счета (недельный, дедлайн 1 день). Следи за 3 метриками (Безопасность/Одобрение/Государство&закон).
7. Выпускай новые версии → AGI = победа. Банкротство/пол метрики = поражение.

## Что есть (фаза 1+2)
Полная петля, RU/EN, обучалки-попапы, события-следствия (пожар/иск/совет — телеграфируются), сатира-тикер, карточки концовок. 0 ошибок, мобильно.
