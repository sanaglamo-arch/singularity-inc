# Singularity Inc. — БАЛАНС: тиры железа и помещений

> Группировка реалистичного списка владельца (25 единиц) в играбельные ступени + помещения. Числа $/электро/аренда = ПЛЕЙСХОЛДЕРЫ, защёлкиваются пруф-симом. Параметры из видения: железо = {м², аренда $/с, электро кВт·ч, цена}; помещение = {м², цена, обслуживание $/с, законность%, безопасность%}.

## Железо — 9 ступеней (старые устаревают, раскрываются по ходу)
| # | Ступень (из 25) | м² | электро кВт·ч | роль |
|---|---|---|---|---|
| 0 | **Старый ноут** (стартер) | 0.05 | 0.04 | открывает клик, аренды НЕТ |
| 1 | **Мини-сервер / неттоп** (Raspberry/неттоп/NAS) | 0.05 | 0.04 | первый пассив (аренда) |
| 2 | **Офисный системник / башенный сервер** | 0.3 | 0.2 | ранний рост |
| 3 | **GPU-сервер (Full-Tower) / настенный шкаф** | 0.55 | 1.0 | первый «ИИ»-намёк |
| 4 | **Стоечный сервер 1U-2U** (нужна серверная комната) | 0.6 | 0.7 | переход на стойки |
| 5 | **Стойка 42U / блейд-шасси** | 2.2 | 9.0 | средний бизнес |
| 6 | **ИИ-стойка 48U (8×H100/B200) / DGX SuperPOD** | 2.7 | 13 | промышленный ИИ |
| 7 | **Модульный ЦОД (контейнер) / малый ряд стоек** | 25 | 300 | масштаб ЦОД |
| 8 | **Гиперскейл ЦОД / флагманский кластер** (сотни тыс. GPU) | 50000 | 120000 | AGI-масштаб |

- Каждая ступень: цена, аренда $/с, электро — кривая (≈×6-10 за ступень), чтобы переход был выгоден, но требовал нового помещения.
- **Инвариант (пруф-сим):** на потолке места суммарная Мощность всегда перекрывает требование след. версии модели.

## Помещения — 5 тиров (место + легитимность)
| # | Помещение | м² | роль | дешёвый ↔ легитимный |
|---|---|---|---|---|
| 1 | **Гараж/комната** (старт) | ~20 | первое железо | — |
| 2 | **Офис** | ~100 | ранний рост | Подвал 60/55 ↔ Бизнес-парк 95/90 |
| 3 | **Серверная комната** (нужен кондиционер) | ~300 | стойки | Склад 65/60 ↔ Серт. площадка 97/95 |
| 4 | **Малый ЦОД** | ~2 000 | промышленное | Серая зона 70/65 ↔ Тир-III ЦОД 99/98 |
| 5 | **Кампус ЦОД** | ~50 000 | AGI-масштаб | На заповеднике 60/70 ↔ Зелёный кампус 99/99 |

- «законность%/безопасность%»: дешёвые варианты ниже → выше шанс иска/пожара (телеграф). Дорогие почти исключают.
- Обслуживание $/с растёт с тиром; больше м² → больше железа влезает (потолок Мощности).

## Сотрудники (числа-плейсхолдеры)
| Роль | Эффект (на единицу, с насыщением) |
|---|---|
| Юрист | −x% к давлению государства |
| Безопасник | −x% к риску опасности |
| Маркетолог | +x% к одобрению |
| Экономист | −x% к налогу |
Насыщение: эффект логарифмический (100 не обнуляют). Зарплаты → в недельный счёт.

## Сложности — оси (числа под пруф-сим)
| Ось | Легко → Невозможно |
|---|---|
| Агрессия/скорость ривалов | медленные → гонят к AGI |
| Размер спроса | щедрый → тощий |
| Тяжесть событий при том же % | мягкие → жестокие |
| Стартовая касса | подушка → впритык |
| Налог | низкий → высокий |
| Терпение совета (грейс ликвидности) | долгое → короткое |

## Пороги версий моделей (под пруф-сим)
- vN требует порог Мощности (показан осязаемо: «≈ 5 стоек 42U»). Растёт ×N за версию. AGI = топ-ступень железа на кампус-масштабе.
- Спрос рынка растёт по эрам (gen-гейтнуто), чтобы доход догонял экспоненту счетов.
