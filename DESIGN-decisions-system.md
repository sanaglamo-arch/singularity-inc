# Singularity Inc. — Система НОВОСТЕЙ и РЕШЕНИЙ (дизайн-спека на «добро»)

> Новый стержень игры по заданию заказчика: решения всплывают **во время игры**, бьют **конкретно**, база **большая** и на **реальных** новостях. Основано на ресёрче: (а) механики эталонов (Reigns/Paperclips/Frostpunk/Democracy/Suzerain/CK/This War of Mine), (б) каталог 130 реальных AI-событий ([[DESIGN-events-catalog]]), (в) аудит наших систем (движок карточек у нас УЖЕ есть — расширяем).

## 1. Видение (одной фразой)
Ты ведёшь AI-лабу через поток **дилемм из реальной индустрии**: гнать быстро или безопасно, купить данные или спиратить, взять деньги гиганта или остаться независимым. Каждый выбор сдвигает ресурсы и метрики, копит **скрытый долг** (alignment/risk), который **детонирует позже**. Гонка конкурентов к AGI — часы, что тикают сами.

## 2. Ключевое решение UX: НЕ всё прерывает (иначе усталость)
Три приоритета события (из эталонов — фикс «бесит, когда отвлекает в простое»):
- **`interrupt`** — модалка поверх игры, ставит прогресс на паузу, требует выбор СЕЙЧАС. Только крупные моменты (кризис, рывок конкурента, акт-дефайнинг). Редко.
- **`bankable`** — падает в **инбокс с бейджем** и мягким таймером (напр. 7 дней); игрок решает в своём темпе. **Большинство решений тут.**
- **`ambient`** — само-резолвится дефолтом, видно только в новостной ленте. Флавор + лёгкий дрейф.

→ «Заставлять решать» = interrupt-моменты бьют точно и весомо; рутину не превращаем в спам.

## 3. Движок (у нас уже есть основа — `C.CARDS` + `resolveCard` + `applyEffect`)
**События — это данные, не код.** Один генерик-рантайм читает декларативные записи. Стрельба — **тик-лотерея по стейт-гейтнутому пулу** (модель Reigns «мешок» + CK weighted-lottery) + **скриптовые акт-биты**:
```
каждый игровой день:
  1. двигаем экзо-часы: конкуренты +AGI (быстрее, когда ты близко); мировой Risk дрейфует вверх с масштабом
  2. скриптовый бит ждёт? → выстрелить (акт-переход, звено цепочки)
  3. иначе ambient-лотерея (кулдаун пейсинга ~1 решение / 2–4 дня):
     пул = события где trigger()==true И акт совпал И не на кулдауне И (once? !выстрелено)
     вес = base × Π(weight_mods по стейту)   // кризис-карты доминируют мешок когда risk высокий
     тянем 1 по весу; пусто/«тихий день» → дыши
```
Анти-кластер: shuffle-bag внутри категории (без повторов и комков). Per-category дневные капы (не три PR-кризиса подряд). «Тихий пол» — паузы игроку.

## 4. Схема события (расширяем текущую `{id, choices:[{effect}]}`)
```jsonc
{
  "id": "data.scrape_or_license",
  "act": [1,2], "category": "legal", "weight": 100,
  "cooldown_days": 90, "once": false, "priority": "bankable",
  "trigger": { "AND": [ {"meter.compute":">=500"}, {"NOT":{"flag":"sued_copyright"}} ] },
  "weight_mods": [ {"factor":2.0,"when":{"meter.risk":">=60"}} ],
  "title":"loc...","desc":"loc...","speaker":"counsel",
  "options": [
    { "id":"pirate", "tooltip_meters":["cash","risk"],          // показываем КАКИЕ метрики, прячем +/−
      "effects": { "resource":{"cash":"+0"}, "meter":{"marketShare":"+6","risk":"+12"},
                   "set_var":{"legal_debt":"+1"},
                   "schedule":{"event":"legal.lawsuit_hits","delay_days":120,"chance":0.5} } },
    { "id":"license", "effects": { "resource":{"cash":"-300"}, "meter":{"trust":"+5","risk":"-4","marketShare":"-2"} } }
  ]
}
```
**Грамматика эффектов:** `meter`(кламп-дельты), `resource`(транзакции, можно в минус=долг), `set_flag/clr_flag`, `set_var`(аккумуляторы вроде `alignment_debt`), `schedule`(отложенный коллбэк с `chance`), `rival_effect`(толкнуть AGI конкурента), `buff`(таймер-множитель). Опционально `inertia` на метрику — дельта как скользящее среднее за K дней («смазанные» последствия à la Democracy).

## 5. Метрики как ОППОЗИЦИОННАЯ паутина (чтоб не было «безопасного центра»)
- **alignment ↔ risk** обратно связаны: низкий alignment тихо растит risk каждый тик (долг). Высокий risk → чаще/жёстче incident-события.
- **marketShare/valuation** тянет вверх скорость/выпуск → толкает **alignment↓, risk↑**. Чистая скорость выигрывает в моменте, проигрывает вдолгую.
- **publicTrust** — медленная метрика (высокая инерция): тяжело поднять, легко обрушить инцидентом. **Гейтит лучшие опции** (регуляторная добрая воля, добродетельный PR) и гасит risk-кризисы.
- **AGI-прогресс конкурентов** — твои часы Судного дня: растёт быстрее, когда растёт ТВОЙ (ты запускаешь гонку) и когда ты публикуешь/опенсорсишь. Чем ближе ты — тем злее мир (ratchet из Plague Inc).

**Пороги провала/эскалации:** risk=100 → катастрофа; alignment=0 → бунт/исход талантов; trust=0 → регуляторное закрытие; cash<0 долго → банкротство; **конкурент достиг AGI первым → проигрыш гонки**. У порога — ультиматум на 2 хода (Frostpunk).

## 6. Контент-план (из 130 реальных → большая база)
10 категорий: regulation · compute/chips · talent · safety/incidents · legal · open-source · product/market · funding · geopolitics · PR/culture. Цель v1: **~70–90 событий** (по 6–10 на категорию), размечены по актам; дальше доращиваем до 150+. Многоступенчатые **арки-цепочки**: Сага совета, Расплата за копирайт, Геополитика compute, Acqui-hire/антитраст. **2 сюжета — трезво, без сатиры** (помечены в каталоге).

## 7. Акты = смена экономики (Paperclips-стиль), привязка к AGI
- **Акт 1 Стартап:** дефицит cash; найм, compute, узкие модели; первые safety-дилеммы; копятся аккумуляторы долга.
- **Акт 2 Frontier-гонка:** дефицит compute; конкуренты видны и близко; входят регуляторы (ratchet); **детонируют отложенные последствия Акта 1.**
- **Акт 3 Эндшпиль AGI:** долг alignment/risk предъявляется; решения экзистенциальны; финальная развилка — выкатить возможно-несогласованный AGI ради победы ↔ придержать и дать конкуренту выиграть. **Тема = механика.**

## 8. Подача (UI)
Две метрики с живыми стрелками давления (risk + alignment на видном месте); новостная лента = нарратив + сигнал сложности; **инбокс с бейджем** для bankable; коллбэки «они это запомнили» при срабатывании отложенного; recap-карты в конце акта + эпилог по накопленному стейту.

## 9. Анти-провалы (чек-лист на билд)
Снежный ком → конкуренты ускоряются с твоим лидом, risk компаундит. Save-scum → commit-on-fire + рандом `chance` на отложенных. Фейк-выбор → каждый эффект гейтит что-то позже; нет строго доминирующей опции. Усталость → bankable-инбокс + тихие полы. Стоимость письма → QBN-сторилеты + вариативность реакции (одно событие — разный эффект по твоему «характеру»-флагам).
