# Singularity Inc. — Аудит (3 адверсариальных) + РЕЗОЛЮЦИИ (что чиним)

> 3 жёстких аудита: экономика-стресс · худшие сценарии · полнота. Ниже — каждая дыра + моё решение. Код заморожен; это спека правок. Решения мои (заказчик: «доработай на своё усмотрение»).

## A. ЭКОНОМИКА — найдено (КРИТИЧНО, подтверждено числами кода)
1. **Строить = ловушка НА КАЖДОМ тире** (revenue ∝ cps^0.72 сублинейно, burn линеен) → маржинальная покупка всегда net-минус. Лок «строить выгодно» в коде **ложь**.
2. **ЭКСПЛОЙТ «выпусти-минимум и ПАРКУЙСЯ»**: купи минимум Мощности под сток поколения, выпусти (×1.68 дохода бесплатно), **перестань покупать** → паркуешься в плюс (+150k/мес), строишь — в минус (−993k/мес). Оптимально строить КАК МОЖНО МЕНЬШЕ — инверсия idle-игры.
3. **Невозможно МАТЕМАТИЧЕСКИ непроходим**: даже при доле 91% + доверие 100, rev/burn ≤ 0.75 всегда. Банкрот к поколению 3-4. Сломано, не «брутально».
4. **МЁРТВЫЙ КОД: «перм. ×доход» раундов НЕ РАБОТАЕТ** — `genRevenueMult()` (с round-mult + revMult-лестницей) экспортится, но не множится в `moneyRate()`. Раунды = только разовый кэш; revMult-лестница (2.2…16) мертва.
5. **Пейсинг ~46 реальных дней**, не 3 недели — боттлнек = время набора СТОКА Мощности (AGI = 2T стока), не обучение. Поздние поколения требуют ×10 стока → тысячи дней грайнда. Выстроить себя из этого нельзя (ловушка #1).
6. Счета/налоги из дизайна **в коде не реализованы** (электро — непрерывная доля burn, налогов нет).
7. ✅ Численно стабильно (NaN/overflow нет) — единственная крепкая ось.

### РЕЗОЛЮЦИЯ экономики (целевая спека под билд)
1. **Revenue ~линеен в Мощности** (ADOPTION_EXP→~0.95-1.0 / поднять REV_COMPUTE_COEF / срезать compute-долю burn) → маржинальная Δrev ≥ Δburn **с ~поколения 4**. → убивает парк-эксплойт (рост снова оптимален).
2. **Подключить round-mult + revMult-лестницу** в `moneyRate()` → раунды дают компаундинг, поздние поколения масштабируют доход.
3. **Перетюнить Невозможно** чтоб rev/burn мог >1.0 хорошей игрой (смягчить burnMult 1.5→~1.3 или computePrice 1.4→~1.25).
4. **Чинить сток-пейсинг**: срезать поздние computeReq ~×10 (или быстрее растить cps) → AGI ~3 недели через СТРОЙКУ, не через ожидание.
5. **Обязательный пруф-сим** перед билдом: дисциплинированный игрок выигрывает Easy/Normal/Hard, выживает-на-грани Impossible; жадный/не-выпускающий/хоардер — падают. Без пруфа не строим.
6. **«Деньги из ниоткуда» (заказчик):** суммы раундов соразмерные (не «20M в гараже»), поданы как привлечение инвестиций с видимой дилюцией; lucky-cash редко/мало; всё подписано.

## B. ЧЕСТНОСТЬ / СПИРАЛИ СМЕРТИ — найдено → РЕЗОЛЮЦИЯ
1. **Электро-неуплата = спираль** (отключение→нет дохода→нечем платить) без пола. → **частичное отключение −30% (не 0)** + форс-раунд/займ-ультиматум ДО отключения. Всегда есть рычаг.
2. **«Обогнали к AGI» = невидимые часы** — проиграл на 1-й день 20-дн обучения, узнал через 20. → **постоянный HUD «отрыв в гонке» (амбер/красный) + рычаг** (спринт/саботаж-решение/видно заранее).
3. **Уклонение от налогов = скрытая ловушка**. → **«Лояльность гос-ва» — видимая метрика**, падает на каждом уклонении, телеграф порога национализации + рычаг (выплата недоимки/амнистия).
4. **v9→v10 обрыв наказывает за стройку**. → сгладить кривую computeReq; рывок дохода v9 математически покрывает burn v10.
5. **AFK→банкрот** (делегат не спасает; idle-игра наказывает за idle). → делегат под мандатом «не умри» авто-берёт раунд/платит счета; ИЛИ долговой таймер/счета замедляются в офлайне.

## C. ДОМИНАНТНЫЕ СТРАТЕГИИ / ФЕЙК-ВЫБОР — найдено → РЕЗОЛЮЦИЯ
1. **«Гнать без Safety» доминантно** (Safety только гасит риск, скипается). → **дать Safety ПОЛОЖИТЕЛЬНУЮ тягу** (высокая Безопасность → trust-гейтнутые контракты/доход/быстрые «доверенные» релизы). «Баланс» — реальная стратегия, не трусость.
2. **Выпуск-как-готов VS выпуск-спайкает-инциденты** воюют. → риск инцидента копится от **недовложения в Safety во времени**, не от акта выпуска (выпуск — спасательный круг игрока).
3. **4 метрики схлопываются в один «слайдер добродетели»**. → зашить **реальные кросс-давления** (платишь налоги/комплаенс → гос↑ но индустрия↓/мораль↓; опенсорс → одобрение↑ но лид/доля↓). И метрики **ОТКРЫВАЮТ ДВЕРИ** (контракты/сделки), не только штрафуют.

## D. ЕДИНИЦЫ / ЯСНОСТЬ — найдено → РЕЗОЛЮЦИЯ
1. **Runway в разных единицах** (месяцы vs дни). → **в ДНЯХ** везде (под «День N» + долговой таймер). Согласовать все доки.
2. **«$/мес» при 60-сек днях путает; хотим /сек**. → ставки показываем **/сек** (как чувствуется), формулы $/мес — внутренний слой.
3. **Мощность = и поток и запас** (двойной смысл). → разделить «**Мощность/сек (мотор)**» vs «**накопленная Мощность (топливо для обучения)**» + teach-on-first.
