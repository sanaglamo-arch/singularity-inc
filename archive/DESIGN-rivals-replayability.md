# Singularity Inc. — Динамичные конкуренты, реиграбельность, рекорды (дизайн на «добро»)

> Бриф заказчика (одобрено + развить): 4 сложности (+уникальные ситуации на «Невозможно»), рейтинг по имени компании игрока, новости про ВСЕ компании, БАЗА названий конкурентов со случайным выбором при старте, конкуренты МЕНЯЮТСЯ по ходу (банкротятся, входят новички), рекорды по сложностям в статистике. Цель — каждый забег ощущается свежим.

## 1. 4 УРОВНЯ СЛОЖНОСТИ + уникальные ситуации «Невозможно»
4 уровня: **Легко / Норма / Сложно / Невозможно** (таблица множителей — в `DESIGN-depth-redesign.md` §5).

**«Невозможно» имеет ЭКСКЛЮЗИВНЫЙ пул чёрных лебедей** (на других уровнях их НЕТ) — экзистенциальные, с таймером:
| # | Ситуация | Удар | Выход |
|---|---|---|---|
| 1 | **Эмбарго на compute** | за ночь −50% мощности (экспорт-бан) | срочно эффективность/свой кремний/серый импорт |
| 2 | **Картель конкурентов** | альянс против тебя: ценовая война + рейд талантов разом | поднять trust/долю, перекупить участника |
| 3 | **Крот** | топ-исследователь — шпион, твоя последняя модель утекла конкуренту (−поколение лида) | контрразведка (раньше), правовая война |
| 4 | **Флэш-крах** | пузырь лопнул: оценка −50%, раунды закрыты N ходов | резать burn, венчур-долг, дожить |
| 5 | **Приказ регулятора удалить модель** | тяжёлый инцидент → требование снести фронтир-модель | подчиниться (−поколение) ИЛИ драться (риск национализации) |
| 6 | **AGI-паника** | конкурент объявил почти-AGI → глобальная экстренная регуляция бьёт всех, тебя сильнее | safety-репутация, лобби |
| 7 | **Исход талантов** | вирусное «doomer»-письмо → массовые увольнения по индустрии | высокий trust удерживает, иначе −исследователи |
| 8 | **Энергокризис** | электро ×3 + мораторий общины на расширение ДЦ | свой источник энергии, эффективность |
Эти 8 делают «Невозможно» **отдельным, жёстким опытом**, а не просто «числа хуже».

## 2. РЕЙТИНГ/СТЕНДИНГ ПО ИМЕНИ КОМПАНИИ
В таблице гонки/доли вместо «Ты/You» — **`companyName` игрока** (то, что он ввёл на старте). Везде, где раньше было «ты»: стендинг, новости, отчёты, концовки.

## 3. НОВОСТИ ПРО ВСЕ КОМПАНИИ (живой индустриальный фид)
Новости генерят не только твои события, но и **конкуренты как самостоятельные акторы**:
- «**{rival}** выпустил модель, бьющую всех ×3 по бенчмаркам — это шок» → их доля/AGI скачок, твоя позиция падает.
- «{rival} закрыл раунд $Xмлрд», «{rival} переманил звезду из {rival2}», «у {rival} скандал — модель опозорилась», «{rival} обвинён в краже данных».
- «{rival} **обанкротился**», «{rival} **поглотил** {rival2}», «никому не известный **{newcomer}** ворвался на рынок».
Фид становится **ареной всей индустрии**, а не только твоим зеркалом. Иконки по типу (релиз/скандал/деньги/M&A/новичок).

## 4. БАЗА НАЗВАНИЙ КОНКУРЕНТОВ + случайный выбор при старте
Пул **~40 названий с архетипами** (у каждого — поведение). При **новой игре случайно выбираются N конкурентов** (N зависит от сложности: легко 2-3, невозможно 4-5). Стартовые доли/AGI распределяются. Игрок — один из N+1.

**Архетипы** (определяют траекторию):
- **Джаггернаут** (бэк Big Tech, ровный мощный рост): Titan AI, Vantage Intelligence, Apex Cognition, Borealis AI, Helion.
- **Safety-любимчик** (медленно, но trust высок, редко падает): Aegis AI, Covenant Labs, Sentinel Mind, Concord AI, Bastion.
- **Безбашенный дисраптор** (рвёт быстро, но скандалы/крахи): Velocity AI, Moonshot Labs, Ignis, Overclock AI, Rampant Systems.
- **Опенсорс-инсургент** (коммодитизирует, давит ценой): OpenMind Collective, Commons Intelligence, Freethought AI, Llamatech.
- **Суверенный/иностранный** (гос-бэк, геополитика): Red Phoenix AI, Volga Neural, Bharat Intelligence, Crescent AI, Nihon Cognition.
- **Стелс-единорог** (тихий, внезапные рывки): Cipher Labs, Null Systems, Obscura AI, Stealthwave, Quietfront.
- **Сатира-хайп** (комичные, нестабильные): GPT-Goblin, Infinite Monkey AI, Basilisk Labs, Paperclip Maximizers Inc, Doomscroll AI, Hype Cycle AI, Ramen Compute, Cerebra, OmniNet.
(Финальный список добью до 40+ при реализации; архетип → AI-логика поведения.)

## 5. ДИНАМИЧНЫЕ КОНКУРЕНТЫ — жизненный цикл (все сценарии)
Роутер раз в N времени / на событиях прогоняет жизнь конкурентов:
- **Рост/спад** по архетипу (джаггернаут ↑ ровно; дисраптор ↑↑ потом риск краха; стелс — внезапный скачок).
- **Релиз модели** → скачок доли/AGI + новость.
- **Скандал/инцидент** → −trust/доля (можешь воспользоваться).
- **Банкротство** (слабый + неудача/высокий burn) → выходит из стендинга, доля перераспределяется, новость.
- **Поглощение** (крупный покупает мелкого) → консолидация, новость; мелкий исчезает.
- **Слияние** двух → джаггернаут.
- **Новый вход** (dark-horse из неиспользованного пула) → внезапно появляется, может рвануть («неизвестная {newcomer} рвёт всех»).
- Игрок по-прежнему может **поглощать** конкурентов (механика есть).
- На «Невозможно»: чаще новички, агрессивнее, координация (картель).
**Итог:** поле боя живёт само — никогда не один и тот же расклад.

## 6. РЕКОРДЫ ПО СЛОЖНОСТЯМ (статистика)
Постоянная структура `records[difficulty] = { bestShare, bestValuation, reachedAGI, fastestAGIdays, bestEnding, games, wins }`.
В Stats — секция **«Рекорды / Зал славы»**:
> Невозможно — 66% рынка · AGI за 28 дней · 1 победа
> Легко — 90% рынка · AGI за 12 дней · 3 победы
Это мета-прогресс и повод перезайти на уровень выше. Сохраняется между играми (не сбрасывается новой игрой).

## 7. ПОЧЕМУ КАЖДЫЙ ЗАБЕГ СВЕЖИЙ (реиграбельность)
- Разный набор конкурентов (из 40+) каждый старт.
- Их архетипы → разные траектории и драмы.
- Динамика (банкротства/новички/M&A) → расклад меняется по ходу.
- Сложность меняет правила (а «Невозможно» — ещё и эксклюзивные ситуации).
- Рекорды по сложностям → цель «пройти на следующем».
- Своё имя компании в рейтинге и новостях → личная история.

## 7.5. ДИСПЕРСИЯ / РАНДОМ — «нет двух одинаковых забегов» (по заказчику)
**Цель заказчика:** две одинаковые сессии, одинаковая сложность, одинаковые действия — но в одной захватил рынок, в другой обанкротился. Это и есть кайф.

**Куда вшиваем рандом (несколько слоёв):**
1. **Сид мира при старте** (по сложности): случайный набор конкурентов + их архетипы + **стартовый «климат рынка»** + стартовый модификатор-сценарий (напр. «ты с лишним кэшем, но конкурент уже впереди» / «дешёвый compute, но регуляторы злые»).
2. **Вероятностные исходы решений:** многие выборы резолвятся БРОСКОМ — «гнать быстро → 55% вирусный хит / 45% инцидент». Тот же выбор — разный результат. (Движок уже умеет `chance`.)
3. **Климат рынка циклами:** макро-состояние дрейфует случайно — бум/спад раундов, скачки цены compute, волны хайпа, настроение регуляторов — бьёт всех, разное каждую игру и во времени.
4. **Волатильность конкурентов:** взлёт/крах стохастичен по архетипу — дисраптор может рвануть к AGI или схлопнуться; каждый раз иначе.
5. **🍀 Фортуна в ОБЕ стороны (критично!):** не только беды, но и **удача** — вирусный момент, кит-клиент, гений сам пришёл, конкурент споткнулся в твою пользу. Иначе рандом = только наказание. Везение должно давать шанс **доминировать**, как и невезение — обанкротиться.
6. **Броски инцидентов:** риск инцидента — это вероятность; тот же уровень иногда кусает, иногда нет.
7. **Дисперсия растёт со сложностью:** Легко = низкий рандом (предсказуемо, учишься); Невозможно = высокий + чёрные лебеди (на нервах).

**⚠️ Единственный guardrail (чтоб «захватывающе», а не «дешёвый произвол)»:** каждый плохой бросок **телеграфируется заранее + есть рычаг отыграться.** Тогда:
- **Жёсткое одинаковое действие игрока → дикие качели** (твой кайф: то доминируешь, то банкрот).
- **Умная реактивная игра → выруливаешь** (мастерство пишет концовку).
Рандом создаёт **ситуацию и историю**; скилл — **ответ**. Это разница между «вот это поворот!» и «игра меня кинула». Держим первое.

**Бонус-идея:** показывать/делиться **сидом** забега («продержись на сиде #4821») — челлендж и хвастовство.
