# Singularity Inc. — Индекс документации проекта

> Единое оглавление всех дизайн-решений. Каждая обсуждённая с заказчиком идея фиксируется здесь и в соответствующем доке (всё под git). Источник истины — эти файлы, не переписка.

## Видение и план
- **GAME-DESIGN.md** — базовый GDD: реалистичный AI-тайкун, без сбросов, месячная дуга, поколения моделей → AGI.
- **ROADMAP.md** — фазовая стратегия лида (стабилизация → ясность → fun → полировка → mobile → launch).
- **STATUS-REPORT.md** — живой журнал работ (отчёт «для начальства»), пункт после каждого захода. Новое сверху.
- **REWRITE-PROGRESS.md** / **BALANCE.md** — прогресс строителя и экономика.

## Дизайн-доки (по системам)
- **DESIGN-decisions-system.md** — движок решений: события=данные, лотерея-пейсер, 3 приоритета (interrupt-модалка/bankable-инбокс/ambient-лента), оппозиционные метрики, отложенный «долг». _Статус: реализовано (Фазы 1-3)._
- **DESIGN-events-catalog.md** — каталог 130 реальных AI-событий (2019-2026) по 10 категориям — сырьё для дилемм. _Реализовано 55 событий._
- **DESIGN-exec-team.md** — руководящая команда + офлайн-делегирование: лестница ~10 тиров до «Потного техдиректора» (~15 дней), мандат, отчёт «Пока тебя не было». _Реализовано._
- **DESIGN-depth-redesign.md** — РЕДИЗАЙН ГЛУБИНЫ: экономика **burn→runway**, фейлы (банкротство + враждебное поглощение-ультиматум + национализация), ставки=% от масштаба + тиры, **«Элаймент»→«Безопасность»+«Риск инцидента»** (учим через скандал), **4 сложности**, переписанные сценарии по актам. _Одобрено, в очереди на билд._
- **DESIGN-rivals-replayability.md** — динамичные конкуренты + реиграбельность: база ~40 названий с архетипами + случайный выбор при старте, новости про ВСЕ компании, динамический жизненный цикл (банкротства/новички/M&A), **4 сложности + 8 эксклюзивных «чёрных лебедей» на Невозможном**, рекорды по сложностям в Stats, **слои рандома** (сид мира, вероятностные исходы, климат рынка, фортуна в обе стороны, дисперсия растёт со сложностью) + guardrail честности. _Одобрено, в очереди на билд._

## Что одобрено и ждёт реализации (сводка)
1. Экономика burn/runway + HUD «runway в месяцах».
2. Фейлы: банкротство, поглощение-ультиматум, национализация.
3. Ставки масштабируются с размером (% + тиры пулов).
4. «Безопасность» + «Риск инцидента» вместо «Alignment».
5. 4 уровня сложности + эксклюзив «Невозможно».
6. Динамичные конкуренты + база названий + реиграбельность.
7. Слои рандома / высокая дисперсия (нет двух одинаковых забегов).
8. Рекорды по сложностям в Stats.
9. companyName игрока в рейтинге/новостях/концовках.
